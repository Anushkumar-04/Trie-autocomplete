\# Trie Autocomplete in C++ with WebAssembly



This is a simple web app that performs autocomplete using a Trie built in C++, compiled to WebAssembly (WASM) using Emscripten.



\## 💻 Technologies



\- C++

\- Emscripten (WASM)

\- HTML + JS



\## 🚀 Usage



1\. Install Emscripten SDK (once)

2\. Run `emscripten-build.bat` to build `trie.wasm` and `trie.js`

3\. Open `index.html` in browser (use Live Server or host locally)



\## 🌐 Hosting



\- GitHub Pages or Netlify (static only)
